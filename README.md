# Zomato-Analytics-Project
This project presents an interactive Zomato Analytics Dashboard developed using Microsoft Power BI to analyze restaurant distribution, customer ratings, pricing, cuisines, location, and service availability.

The objective of this project is to transform raw restaurant data into meaningful business insights that can support data-driven decision-making for restaurant businesses, customers, and business stakeholders.

The analysis focuses on restaurant performance across different cities, countries, cuisines, ratings, pricing categories, and service offerings such as table booking and online delivery.
